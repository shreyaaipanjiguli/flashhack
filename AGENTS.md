# Instructions for AI Coding Agents

1. Analyze requirements before implementation.
2. Explain architecture and technology choices.
3. Build features incrementally.
4. Write modular and maintainable code.
5. Do not modify unrelated files.
6. Never expose API keys or secrets.
7. Never overwrite existing work without approval.
8. Test features after implementation.
9. Explain important code and debugging decisions.
10. Keep README.md and DECISIONS.md updated.
11. Use Git branches for new features.
12. Never claim untested functionality works.
13. Ask before destructive terminal commands.
